# Hima Lakshmi Sowjanya — Portfolio

A responsive, single-page portfolio built with plain HTML, CSS and JavaScript.

## Included
- About
- Skills
- Selected Projects
- Education
- GitHub link
- Clickable email (`mailto:`)
- Responsive mobile navigation
- Scroll reveal animations
- No Experience / Certifications / Achievements sections

## Run locally
Open `index.html` directly in a browser, or use VS Code Live Server.

## Deploy
This is a static site, so it can be deployed directly to Vercel, Netlify or GitHub Pages.
